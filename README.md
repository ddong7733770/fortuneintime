# Fortune in Time 시운 時運

시간에 따라 달라지는 운세를 보여주는 모바일 중심 정적 웹사이트입니다. 6개 언어(한국어, 일본어, 중국어 간체, 영어, 스페인어, 인도네시아어)로 제공하고, 애드센스 광고로 수익을 냅니다.

- 서버가 필요 없습니다. 운세 계산은 모두 사용자의 브라우저에서 하고, 입력한 정보는 그 기기에만 저장됩니다.
- `node build.mjs` 한 번으로 `dist/` 폴더에 사이트 전체(약 295쪽)가 만들어집니다.

## 폴더 구성

| 경로 | 내용 |
| --- | --- |
| `site.config.mjs` | **배포 전에 고칠 곳은 이 파일 하나뿐입니다.** 도메인, 문의 이메일, 애드센스, GA4, 이미지 경로 |
| `src/engine.js` | 운세 엔진 (같은 입력, 같은 날짜면 언제나 같은 결과) |
| `src/i18n/*.js` | 언어별 문구 6개 |
| `src/content.js` | 시간 다이얼 그림, 정적 페이지 문단 (빌드와 브라우저가 함께 사용) |
| `src/client/` | 화면 동작(`app.js`), 디자인(`style.css`), 첫 페이지(`root.js`), 정적 페이지 날짜 갱신(`static.js`) |
| `public/` | 그대로 복사되는 파일: 이미지, 아이콘, 공유 미리보기(OG) 이미지 |
| `build.mjs` | 페이지 생성기 |
| `scripts/make-images.mjs` | 임시 이미지와 OG 이미지 생성기 (필요할 때만 실행) |

## 내 컴퓨터에서 확인하기

```bash
npm install
npm run dev        # 빌드 후 http://localhost:4321 에서 열림
```

`localhost`나 주소 끝에 `?ads=preview`를 붙이면 광고 자리가 점선 상자로 보이고, '광고 보고 한 번 더' 버튼이 5초짜리 가짜 광고로 동작합니다. 실제 사이트에서는 애드센스 ID를 넣기 전까지 광고 자리가 보이지 않습니다.

## 배포 순서 (Cloudflare Pages)

- GitHub 저장소: https://github.com/ddong7733770/fortuneintime
- Cloudflare Pages 프로젝트 이름: `fortuneintime` → 기본 주소 https://fortuneintime.pages.dev (`site.config.mjs`의 `siteUrl`)

1. **GitHub에 올리기**: 이 폴더를 저장소에 올립니다 (`node_modules/`, `dist/`는 자동 제외).
   ```bash
   git init && git add . && git commit -m "Fortune in Time"
   git branch -M main
   git remote add origin https://github.com/ddong7733770/fortuneintime.git
   git push -u origin main
   ```
2. **Cloudflare Pages 만들기**: Workers & Pages → Create → Pages → Connect to Git → `fortuneintime` 저장소 선택, 프로젝트 이름 `fortuneintime`
   - 이후 GitHub에 올릴 때마다 자동으로 빌드·배포되므로, 대시보드에 파일을 직접 끌어다 놓을 필요가 없습니다.
   - 빌드 명령: `npm run build`
   - 출력 폴더: `dist`
   - 환경 변수: `NODE_VERSION` = `22`
3. **명령어로 바로 올리기(선택)**: GitHub 연결 없이 올릴 때는 `npm run build` 후 `npx wrangler pages deploy dist --project-name fortuneintime`
4. **도메인 연결(선택)**: 도메인을 사면 Pages 프로젝트 → Custom domains에 추가하고(HTTPS 자동), `site.config.mjs`의 `siteUrl`과 `contactEmail`을 그 도메인으로 바꿉니다.
5. **매일 자동 갱신**: Pages 프로젝트 → Settings → Builds → Deploy hooks에서 후크를 만들고, 그 URL을 GitHub 저장소 Secrets에 `CF_DEPLOY_HOOK` 이름으로 저장합니다. `.github/workflows/daily-rebuild.yml`이 매일 한국 시간 00:05에 다시 빌드합니다.
   - 빌드가 늦어져도 정적 운세 페이지는 방문자 기기의 오늘 날짜로 다시 계산되므로 날짜가 틀리게 보이지 않습니다.
6. **구글 서치 콘솔**: 도메인을 등록하고 `https://도메인/sitemap.xml`을 제출합니다.

## 애드센스 연결

1. 사이트를 배포하고 서치 콘솔에서 페이지가 색인되는 것을 확인한 뒤 애드센스를 신청합니다.
2. 승인되면 `site.config.mjs`에 입력합니다.
   ```js
   adsense: {
     client: 'ca-pub-1234567890123456',
     slots: { A: '1111111111', B: '2222222222', C: '3333333333', tab: '4444444444', content: '5555555555' },
   },
   ```
   - `A` 운명 바꾸기 아래, `B` 분야별 운세 아래, `C` 행운 번호를 뒤집은 뒤, `tab` 궁합·타임머신·부적 하단, `content` 정적 운세 페이지 본문
3. 다시 배포하면 광고 스크립트, 광고 자리, `ads.txt`가 함께 들어갑니다.
4. 애드센스 화면에서 할 일
   - **자동 광고**: 앵커(화면 하단)와 전면 광고(페이지 이동 시)를 켭니다. 결과 탭은 서로 다른 페이지라 탭을 옮길 때 전면 광고가 작동합니다.
   - **개인정보 보호 및 메시지**: 유럽 사용자용 동의 창(CMP)을 켭니다. 스페인어 방문자에게 광고를 내보내려면 필요합니다.
5. **보상형 광고**(운명 바꾸기 +1회, 부적 고화질 저장): 애드센스나 구글 애드 매니저에서 웹 보상형 광고를 쓸 수 있게 되면, 페이지에 아래 함수를 정의하기만 하면 버튼이 나타나고 연결됩니다.
   ```js
   window.ttfShowRewarded = onGranted => { /* 광고를 보여주고, 끝까지 보면 onGranted() 호출 */ };
   ```

## 지금 나에게 필요한 장소는? (여행지 지도)

운세 탭의 이 영역은 처음에 흐리게 꺼져 있고, 가운데 **출발**을 누르면 시작합니다.

1. **출발지**: 접속한 IP 주소로 Cloudflare가 추정한 대략의 도시를 씁니다. `dist/_worker.js`가 `/api/geo` 주소에서 위치를 알려 주며, 아무것도 저장하지 않습니다. `_routes.json` 설정 때문에 이 주소에서만 실행되어 무료 한도를 아낍니다.
   - 위치를 못 받으면(내 컴퓨터 미리보기 등) 구글 위치 API(키가 있을 때), 그다음 기기 시간대로 출발지를 정합니다.
2. **여행지**: 세계의 힐링 여행지 40곳 중 한 곳을 무작위로 고릅니다. 직전 장소와 겹치지 않게 고릅니다. 문구는 `src/i18n/places/언어.js`와 `src/i18n/places/more/언어.js`, 좌표와 구글 지도 검색어(MAPQ)는 `src/client/place.js`에 있습니다. 여행지 이름을 누르면 구글 지도에서 그 장소가 열립니다.
3. **이동 애니메이션**: 출발지에서 여행지까지 가장 짧은 하늘길을 따라 날아갑니다.
4. **도착 설명**: 여행지 소개 2문장, 그곳의 기운 1문장, 그리고 오늘 가장 약한 분야(재물·연애·일/학업·건강)와 연결한 1문장을 보여줍니다.

**지도 종류**
- `googleMapsKey`가 비어 있으면 내장 세계지도로 그립니다. 비용이 없고 지금 바로 동작합니다.
- 구글 지도를 쓰려면 Google Cloud 콘솔에서 결제 계정을 연결하고 **Maps JavaScript API**를 켠 뒤 API 키를 만듭니다. 키의 **애플리케이션 제한**을 'HTTP 리퍼러'로 하고 `https://내도메인/*`, `https://fortuneintime.pages.dev/*`를 넣어 다른 곳에서 못 쓰게 막아 주세요. 그 키를 `site.config.mjs`의 `googleMapsKey`에 넣고 다시 빌드합니다.
- 구글 지도 불러오기에 실패하면 자동으로 내장 지도로 바뀝니다.

**업로드 주의**: `dist` 폴더 안의 `_worker.js`와 `_routes.json`도 함께 올라가야 출발지가 접속 위치로 잡힙니다. `dist` 폴더를 통째로 끌어다 놓으면 함께 올라갑니다.

## 운세 문장 늘리기

언어별 문장 풀은 `src/i18n/lines/언어.js`에 있습니다. 문장을 조각으로 나눠 이어 붙이므로, 각 목록에 한 줄만 더해도 가짓수가 곱셈으로 늘어납니다.

| 항목 | 구성 | 현재 가짓수 (언어별) |
| --- | --- | --- |
| 가장 좋은 시간 / 조심할 시간 | 열기 8 × 조언 10 × 맺음 2 | 각 160 |
| 재물·연애·일/학업·건강 (운세 탭, 타임머신 오늘·미래) | 상태 4 × 조언 3 × 팁 5 × 3단계, 3문장 | 분야마다 180 |
| 재물·연애·일/학업·건강 (타임머신 지난 날, 과거형) | 과거 상태 5 × 돌아보기 8 × 3단계, 2문장 | 분야마다 120 |
| 타임머신 총평 | 총평 4 × 덧붙임 8 × 4단계 (지난 날은 과거형) | 128 / 128 |

빌드할 때 가짓수를 자동으로 검사합니다. 문장을 지워서 기준(160, 180, 120) 아래로 내려가면 빌드가 멈추고 어느 언어의 어느 항목이 부족한지 알려 줍니다.

## 운명 바꾸기 연출
- 기운이 모임(0.5초) → 운명의 문(천문도·팔괘·오행 문양, 1.3초) → 섬광과 함께 새 운세 카드 등장 → 완료 배지.
- 기회는 새 운세가 만들어지고 화면에 그려진 뒤에만 차감됩니다. 실패하면 차감 없이 기존 운세를 유지합니다.
- 규칙은 기존과 같습니다: 6시·18시 기준 시간대마다 1회(하루 2회), 광고 시청 시 1회 추가.
- 삭제된 12시진 페이지 주소(/언어/hour/…)는 `_worker.js`가 각 언어 첫 화면으로 연결합니다.

## 장소 추천 출발 장면 (픽셀 애니메이션)
- `src/client/place-intro.js`: 96×60 픽셀 캔버스에 7초 동안 그립니다. 밤샘하며 지친 나 → 노트북과 책을 던짐 → 캐리어를 끌고 공항으로 → 공항 입장 → 1초 뒤 비행기 이륙 → 지도 비행.
- 시간대마다 처음 출발할 때만 나오고, '다른 곳으로 다시 출발'에서는 바로 비행합니다. 장면을 누르면 건너뜁니다. 동작 줄이기 설정을 켠 기기에서는 생략됩니다.
- 운명 바꾸기에 성공하면 이번 시간대의 장소 추천이 초기화되어 다시 출발할 수 있습니다.
- 효과음은 `src/client/sfx.js`에서 Web Audio로 직접 만듭니다(소리 파일 없음). 장소 영역 오른쪽 위 버튼으로 끌 수 있고, 선택은 이 기기에 저장됩니다.
- 지도 비행: 비행기 아이콘이 진행 방향으로 회전하며, 엔진 소리와 도착 '딩동'이 납니다.
- 추천 이유: 가장 약한 운 + 출발지에서 본 여행지 방향과 오늘의 행운 방향 비교 + 그곳에서 할 일 + 오늘 점수로 4문장 이상을 만듭니다(`src/i18n/places/reason/언어.js`).
